# HeidiSQL

- **Tipo:** Aplicación de Escritorio nativa (Windows).
- **Resumen:** Cliente gráfico ligero y de alto rendimiento para administrar [[MariaDB]], [[MySQL]], [[SQL_Server]] y [[PostgreSQL]].

### Por qué lo preferimos en el stack local
- **Rendimiento:** Al ser nativo, es infinitamente más rápido que las alternativas web. Puede manejar scripts SQL gigantescos sin colapsar.
- **Versatilidad:** Te permite tener múltiples sesiones guardadas y conectarte a diferentes motores (puedes gestionar tu MariaDB local y un SQL Server de Azure desde la misma ventana).
- **Herramientas integradas:** Excelente visor del registro de consultas en tiempo real y opciones avanzadas de exportación de datos. Es el "cuchillo suizo" definitivo.
