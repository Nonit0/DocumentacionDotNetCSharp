# XAMPP (Servidor Local)

Para desarrollar aplicaciones Backend, necesitamos servidores de bases de datos corriendo en nuestra máquina. Aquí documentamos nuestro servidor local principal.

## ¿Qué es?
Es un paquete de software libre que contiene principalmente un servidor web [[Apache]] y un sistema de gestión de bases de datos **[[MariaDB]]** (o [[MySQL]]).

## Uso en .NET
Aunque no usamos Apache ni PHP en nuestro stack de C# si estamos en Windows (usamos [[Laragon]]), muchos desarrolladores usan [[XAMPP]] simplemente porque es la forma más rápida y amigable de instalar y levantar un servicio de [[MariaDB]] en Windows/Linux haciendo un solo clic en su panel de control (en lugar de usar contenedores [[Docker]] o instalaciones nativas pesadas).
